ChatGPT Proxy Launcher v1.0.0
Windows 快速安装说明

用途
为 ChatGPT/Codex 设置本次启动使用的本地代理，同时保留 Windows 应用包身份。
使用者反馈：Codex 反复“重新连接（Reconnecting 1/5～5/5）”的问题在改用此启动器后恢复正常。
不同原因导致的重连、WSL 或提示词问题仍需分别排查，完整说明见 README.md。

使用前准备
1. 已安装包名为 OpenAI.Codex 的 Windows ChatGPT/Codex 桌面应用。
2. 已安装代理客户端，并启用本地 HTTP 或 mixed 代理端口。
3. Windows PowerShell 5.1、Windows Script Host / VBScript 可用。

安装
1. 右键 ZIP，选择“全部解压”。不要在压缩包预览窗口中直接运行。
2. 先开启代理客户端，再打开解压后的文件夹，双击 Install.cmd。
3. 安装器自动读取系统代理及代理环境变量，识别成功后直接使用。
   无法识别时才提示填写 HTTP / mixed 端口；默认 7890，直接回车即可。
4. 看到“安装完成”后，桌面会出现 ChatGPT Proxy 快捷方式。
5. 如果发现已有安装，确认是否替换启动脚本；不确认则取消，不覆盖原文件。

启动
1. 先开启代理客户端。
2. 保存任务，完全退出 ChatGPT/Codex，包括系统托盘里的进程。
3. 双击桌面 ChatGPT Proxy。

安装位置
%LOCALAPPDATA%\ChatGPTProxyLauncher
安装完成后可以删除下载的 ZIP 和解压目录；日常从桌面快捷方式启动。
如需更换代理端口，先调整代理客户端，再运行 Install.cmd 自动识别并确认更新。
如需手动覆盖，在解压目录的终端运行：
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1 -ProxyPort 7897 -Force
端口在安装时保存到快捷方式，不会每次启动都自动刷新。

注意
- 这不是 ChatGPT/Codex 本体安装包，也不包含代理客户端或代理节点。
- 不需要 Node.js、Python 或编译工具；不要求以管理员身份安装。
- 不自动关闭应用，不启停 WSL，不修改账号、内置提示词或系统全局代理。
- 代理端口应是 127.0.0.1 上的 HTTP / mixed 端口，SOCKS-only 端口不适用。
- 如果安装失败，窗口会保留错误信息；可在项目 GitHub Issues 中反馈脱敏后的报错。

卸载
删除桌面 ChatGPT Proxy 快捷方式，以及安装目录中的两个启动文件：
Start-ChatGPT-With-Proxy.ps1 和 Launch-ChatGPT.vbs。
只有确认目录为空时再删除目录，保留自行存放的其他文件。
